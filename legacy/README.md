# Historical HAROM producer

`run_redstar-harom.csh` preserves the original multi-program database-production
recipe and its old personal paths. It is reference material, not a current demo.
It needs separate ColorVec/HAROM installations and freshly produced node inputs.
Current root runners use the checksum-pinned precomputed Kanoni SDBs and create
isolated runs. See the root README for the tested workflow.
